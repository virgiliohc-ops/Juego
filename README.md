# NÚMEN · El origen de los dioses

Prototipo experimental de mascota virtual para Android, con 5 fases evolutivas, niveles 1 a 20, cuidados, entrenamiento, exploración, minijuego y evoluciones secretas. Funciona sin conexión y guarda el progreso localmente.

## Descargar APK
Abre **Actions → Compilar APK de NÚMEN**. Si la compilación ha finalizado correctamente, descarga **NUMEN-0-3-Android-APK**, extrae el ZIP e instala `NUMEN_0_3_Android.apk`.

## Compilar
La compilación automática utiliza JDK 17, Gradle 8.9, Android Gradle Plugin 8.7.3 y Android SDK API 35. Ejecuta `:app:assembleDebug` y comprueba la estructura y firma del APK.

## Advertencias
Es un prototipo de pruebas. No se ha instalado todavía en un teléfono real. El proyecto está en un repositorio público: cambia su visibilidad a Private si no quieres compartir el código.
